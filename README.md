# Matplotlib Student Marks Dataset

## About the Project
This project demonstrates different data visualization techniques using Python Matplotlib and a Student Marks Dataset.

## Technologies Used
- Python
- Matplotlib
- Pandas
- Jupyter Notebook
- Google Colab

## Jupyter Notebook
`Matplotlib_Student_Marks_Dataset.ipynb`

## How to Run
1. Download the Jupyter Notebook.
2. Open it in Google Colab or Jupyter Notebook.
3. Run each cell.
4. View the generated graphs.

## Purpose
To learn and practice different Matplotlib functions and understand how to create and customize graphs using Python.
